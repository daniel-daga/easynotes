## What is not ours

Files and packages that came from elsewhere keep their own licences. Everything
that ships inside the app or the relay is listed here, and every one of these
licences is compatible with distributing the whole under the AGPL.

| What | Where | Licence | Notes |
| --- | --- | --- | --- |
| Roboto (regular, medium), recompressed to WOFF2 | `app/assets/fonts/` | Apache-2.0 | Text in `app/assets/fonts/LICENSE.txt`, and on the app's licence page. |
| `flutter_rust_bridge` 2.13.0, patched | `third_party/flutter_rust_bridge/` | MIT | The patch is `third_party/flutter_rust_bridge.patch`; see `third_party/README.md`. |
| Cargokit | `app/rust_builder/cargokit/` | MIT or Apache-2.0 | Text in `app/rust_builder/cargokit/LICENSE`. Has a local change to `gradle/plugin.gradle`. |
| Flutter's platform runners and project templates | `app/android`, `app/ios`, `app/linux`, `app/macos`, `app/windows`, `app/web`, `app/rust_builder/{android,ios,linux,macos,windows}` | BSD-3-Clause (Flutter) | Generated by `flutter create`, then edited. |
| Launcher and web icons | `app/android/app/src/main/res/mipmap-*`, `app/web/icons`, `app/web/favicon.png` | BSD-3-Clause (Flutter template) | **Still Flutter's placeholder logo.** Replace them with EasyNotes' own before any store listing: the Flutter logo is a Google trademark. |
| Dart packages | `app/pubspec.lock` | Each package's own | Collected into the app's licence page by Flutter at build time. |
| Rust crates | `Cargo.lock` | Each crate's own | The release workflow writes the app's list, with licences, as `rust-dependencies.tsv`. |

The browser tests fetch `playwright-core` when they run. It is a test tool and
is never shipped.
