# Contributing to EasyNotes

Thanks for looking. EasyNotes is a local-first, end-to-end encrypted notes app:
a Rust core, a Flutter UI and a small relay. The security-critical code is meant
to stay readable without a device or a Flutter SDK in the loop, so the core is
the easiest place to start.

## Before you start

- Read [`SECURITY.md`](SECURITY.md) if you are reporting a vulnerability. Please
  do not open a public issue for one.
- Read [`docs/architecture.md`](docs/architecture.md) for the data model and
  [`docs/decisions.md`](docs/decisions.md) for the decisions the code refers to.
- By contributing you agree that your work is licensed under
  AGPL-3.0-or-later, the project's licence.

## Prerequisites

- A stable Rust toolchain.
- [Flutter](https://flutter.dev) for anything under `app/`.
- [`just`](https://github.com/casey/just).
- Postgres 16 if you want the relay tests that need a database.

The web build additionally needs a nightly toolchain and `wasm-pack`;
`just setup-web` installs them plus `wasm-bindgen-cli`.

## The quick loop

```sh
just test-core        # the core and everything under it, no Flutter needed
just test-all         # core, relay and app
just lint             # cargo fmt, clippy (host and wasm32), flutter analyze
just run-relay        # a relay on 127.0.0.1:8080, storing in memory
just run-linux        # the app on Linux desktop, over the real core
just --list           # everything else
```

Set `DATABASE_URL` to run the relay on Postgres and include its tests. Without
it those tests skip, and a green run without it is a run that skipped the tests
that matter there.

`just test-app` builds the Rust library and the relay binary first, because the
bridge and two-device tests skip without them. A skipped test that reports green
is worse than no test at all: if the count is lower than expected, the binaries
are missing.

## Compatibility across releases

From the first release tag, stored formats stay readable or are refused with an
explicit protocol version ([ADR 0029](docs/decisions.md#adr-0029)). A change to
anything stored — a CRDT key, a sealed format, a local schema, the relay's
tables — makes `every_fixture_set_still_reads` in `relay/tests/compat.rs` fail
against `compat/v0.1.0/`. That is the test doing its job. Before the first
released tag, regenerate the set with `COMPAT_REPLACE=1 just compat-fixtures`
(an empty database in `DATABASE_URL`, and a `pg_dump` of the same major version
as CI's Postgres, 16) and commit it with the change. After the tag, never
regenerate a released set; add a migration instead.

## Code and formatting

- `cargo fmt` and `cargo clippy --workspace --all-targets -- -D warnings` for
  Rust.
- `dart format` only the files you changed. The current SDK's formatter may
  reformat files you did not touch; do not commit that churn.
- Keep `core` free of Flutter and platform policy. It must stay callable from a
  plain `cargo test`.
- The bridge is generated by `flutter_rust_bridge_codegen`; run `just bridge`
  after changing an exported API. The version is pinned with the Dart package
  and the vendored crate in `third_party/flutter_rust_bridge`.

## Web

`just setup-web` installs the web toolchain, `just build-web` builds the
threaded-WASM app. The build needs cross-origin isolation when served
(`Cross-Origin-Opener-Policy: same-origin` and
`Cross-Origin-Embedder-Policy: require-corp`). The browser recipes
(`just web-smoke`, `just web-sync-smoke`, `just web-converge`,
`just web-storage-failure`, `just web-shared-text`) exercise the result
headlessly.

## Using an AI assistant

AI-assisted contributions are welcome. You are responsible for what you submit:
read the diff, run the tests, and do not paste secrets, recovery phrases,
personal data or material you do not have the right to publish. If an assistant
wrote a substantial part of a change, say so in the pull request — it helps
reviewers know where to look.

## Pull requests

- Keep a change focused. One behaviour, one reason, one set of tests.
- Say what you changed and why, and what you ran. A failing test that reproduces
  a bug is the most useful sentence in a report.
- For security reports, use the private advisory flow in [`SECURITY.md`](SECURITY.md),
  not a pull request.
- Be decent. See [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
